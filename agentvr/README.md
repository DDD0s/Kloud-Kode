# 隧道

`tunnel-up.sh` 把大脑上的一个本地端口转发到身体机器，让 Claude Code 能通过
`.mcp.json` 里的 `127.0.0.1` 地址找到身体的 MCP 服务。

```
大脑 127.0.0.1:18787  ──ssh -L──>  身体 127.0.0.1:8787
```

三个环境变量，写在 `agentvr-api/env` 里：

| 变量 | 默认 | 说明 |
|------|------|------|
| `BODY_SSH` | `body` | 身体机器在 ssh 里的名字 |
| `LOCAL_PORT` | `18787` | 大脑这边的端口 |
| `BODY_PORT` | `8787` | 身体那边监听的端口 |

隧道不需要单独守护：API 每次请求前会探测，不通就自动重新拉起。
手动执行也行，脚本会先检查是否已经通着。

完整的搭建步骤见仓库根目录的 `SETUP.md`。
